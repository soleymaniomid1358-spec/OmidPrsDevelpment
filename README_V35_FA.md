# نسخه ۳۵ مسیر رشد

- بهبود مدیریت نشست Supabase و تمدید خودکار Access Token پیش از انقضا.
- تشخیص خطای JWT منقضی‌شده مستقل از کد HTTP و تلاش مجدد درخواست پس از Refresh Token.
- در خطای موقت شبکه، نشست محلی بدون دلیل پاک نمی‌شود؛ در رد شدن Refresh Token، نیاز به ورود مجدد اعلام می‌شود.
- کلید کش سرویس‌ورکر به v35 ارتقا یافت.

برای استقرار، همه فایل‌های ZIP را در ریشه مخزن جایگزین کنید. پس از انتشار، در موبایل صفحه را کامل ببندید و دوباره باز کنید؛ در صورت باقی‌ماندن نسخه قدیمی، داده‌های سایت/PWA را پاک‌سازی و دوباره وارد شوید.
