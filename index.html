پشتیبان و بازیابی اطلاعات

پشتیبان شامل برنامه‌ها، درصد پیشرفت، یادداشت‌ها و ثبت فعالیت‌هاست.

همگام‌سازی بین موبایل و رایانه

برای مشاهده یکسان اطلاعات روی چند دستگاه، یک‌بار اتصال ابری را تنظیم کنید. داده‌ها تا زمان اتصال همچنان روی همین دستگاه ذخیره می‌شوند.

وضعیت: فقط ذخیره‌سازی محلی فعال است.

راهنمای یک‌باره راه‌اندازی فضای ابری
  1. در Supabase یک پروژه بسازید و Project URL و کلید عمومی anon/publishable را وارد کنید.
  2. در SQL Editor کد زیر را اجرا کنید:
create table if not exists public.masire_roshd_data (user_id uuid primary key references auth.users(id) on delete cascade, payload jsonb not null, updated_at timestamptz not null default now());
alter table public.masire_roshd_data enable row level security;
create policy "user reads own data" on public.masire_roshd_data for select to authenticated using (auth.uid() = user_id);
create policy "user inserts own data" on public.masire_roshd_data for insert to authenticated with check (auth.uid() = user_id);
create policy "user updates own data" on public.masire_roshd_data for update to authenticated using (auth.uid() = user_id) with check (auth.uid() = user_id);

از کلید service_role استفاده نکنید. اگر تأیید ایمیل فعال است، ابتدا ایمیل را تأیید کنید. روی دستگاه دوم با همان پروژه و حساب وارد شوید و «دریافت اطلاعات ابری» را بزنید.

ورود پیشنهادهای هوش مصنوعی

فایل JSON خروجی پیشنهادی ChatGPT را بارگذاری کنید. برنامه پیشنهادها را به‌صورت پیش‌نویس اقدام ذخیره می‌کند؛ پیش از اجرا آن‌ها را بررسی و تأیید کنید.

راهنمای تبادل با ChatGPT

ابتدا خروجی اکسل یا JSON را دریافت کنید و همراه با درخواست تحلیل دوره‌ای در ChatGPT بارگذاری کنید. از مدل بخواهید برای هر پیشنهاد، شخص، نقش، شاخص هدف، رفتار قابل مشاهده، موعد و معیار اثربخشی را مشخص کند؛ سپس پیشنهادهای نهایی را در قالب JSON مطابق نمونه وارد برنامه کنید.
