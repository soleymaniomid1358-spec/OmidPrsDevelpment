# مسیر رشد – نسخه ۳۴

## اصلاحات
- اصلاح ترتیب بارگذاری فرم ویرایش فعالیت: ابتدا صفحه تنظیمات و گزینه‌های دسته/والد آماده می‌شوند و سپس اطلاعات همان فعالیت روی فرم قرار می‌گیرد؛ بنابراین دسته اصلی فعالیت از تب خانه با مقدار قبلی جایگزین نمی‌شود.
- افزایش عرض محتوای صفحه در نمایشگرهای بزرگ و اطمینان از اینکه کادر یادداشت روز تمام عرض کارت را می‌گیرد؛ ارتفاع اولیه کادر نیز بیشتر شده است.
- افزودن «یادداشت روز» به‌عنوان آخرین گزینه فیلتر دسته فعالیت در گزارش.
- با انتخاب «یادداشت روز»، یادداشت‌های ذخیره‌شده به تفکیک تاریخ نمایش داده می‌شوند. خروجی اکسل نیز در صورت انتخاب همین گزینه، یادداشت‌های روز را صادر می‌کند.
- افزایش نسخه اسکریپت و Service Worker به ۳۴ برای جلوگیری از استفاده از کش نسخه قبلی.

## اعتبارسنجی
- بررسی نحوی JavaScript با `node --check`.
- بررسی سلامت آرشیو ZIP پس از بسته‌بندی.
- آزمون تعاملی واقعی در مرورگر انجام نشده است.
