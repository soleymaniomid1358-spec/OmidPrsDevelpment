# نسخه ۳۶ مسیر رشد — ماژول RPDS

## ماژول مدیریت و توسعه روابط
این نسخه ماژول RPDS را در خود برنامه مسیر رشد اضافه می‌کند؛ اطلاعات برنامه‌ریزی قبلی حذف یا جایگزین نمی‌شود.

### امکانات
- تعریف، ویرایش و بایگانی اشخاص.
- تخصیص یک یا چند نقش به هر شخص: زیر دست، هم‌سطح، بالادست، خانوادگی، دوست/اجتماعی، مشتری/تأمین‌کننده و سایر.
- ثبت مستمر بازخورد دریافتی، خودبازبینی، بازخورد مشاهده‌شده یا بازخورد ارائه‌شده؛ همراه با زمینه، رفتار عینی، نقاط قوت، موارد قابل بهبود و توصیه مشاوره‌ای.
- ارزیابی شاخص‌های ارتباطی در مقیاس ۱ تا ۵ به همراه شواهد رفتاری.
- تعریف اقدامات بهبود، اولویت، موعد، وضعیت، منشأ پیشنهاد، معیار موفقیت و ثبت نتیجه/اثربخشی.
- گزارش به تفکیک نقش، شخص یا شاخص و امکان فیلتر بازه زمانی، نقش و شخص.
- خروجی Excel سازگار با Excel در قالب SpreadsheetML با شیت‌های اشخاص، بازخوردها، ارزیابی‌ها، اقدامات و راهنمای تحلیل AI.
- خروجی JSON برای ارائه به ChatGPT و ورود مجدد پیشنهادهای AI به شکل پیش‌نویس اقدام.
- اطلاعات RPDS در همان state برنامه ذخیره می‌شود و در پشتیبان JSON و همگام‌سازی ابری موجود برنامه نیز قرار می‌گیرد.

### گردش کار پیشنهادی
1. اشخاص و نقش‌های مرتبط را ثبت کنید.
2. بازخوردها و نمونه‌های رفتاری را به‌مرور وارد کنید.
3. شاخص‌ها را با شاهد عینی ارزیابی کنید.
4. هر بار حداکثر ۲ تا ۳ اقدام اولویت‌دار برای هر شخص فعال کنید.
5. ماهانه یا فصلی گزارش Excel/JSON بگیرید و برای تحلیل به ChatGPT بدهید.
6. پیشنهادهای نهایی را به صورت JSON با کلید `actions` یا `recommendations` بارگذاری کنید؛ اقدامات واردشده با وضعیت «شروع نشده» و منشأ «هوش مصنوعی» ثبت می‌شوند.
7. نتیجه اجرا و شواهد اثربخشی را ثبت و در دوره بعد ارزیابی را تکرار کنید.

### قالب JSON ورود پیشنهاد
```json
{
  "actions": [
    {
      "personName": "نام شخص مطابق برنامه",
      "role": "زیر دست",
      "kpi": "گفت‌وگو و گوش‌دادن مؤثر",
      "title": "عنوان اقدام",
      "description": "رفتار مشخص و قابل اجرا",
      "priority": "متوسط",
      "dueDate": "1405/09/01",
      "source": "هوش مصنوعی",
      "successMeasure": "معیار سنجش اثربخشی"
    }
  ]
}
```

### نکات فنی و محدودیت‌ها
- ساختار RPDS در `state.rpds` و در Local Storage موجود برنامه نگهداری می‌شود؛ کلید داده‌های اصلی برنامه تغییر نکرده است.
- بکاپ کامل فعلی، داده‌های RPDS را نیز شامل می‌شود. هنگام بازیابی بکاپ قدیمی، اگر بخش RPDS وجود نداشته باشد، ساختار خالی آن ایجاد می‌شود.
- ارتباط مستقیم و خودکار با API ChatGPT در این نسخه وجود ندارد؛ تبادل از طریق فایل‌های Excel و JSON انجام می‌شود تا وابستگی به اینترنت/API و ارسال خودکار اطلاعات شخصی ایجاد نشود.
- خروجی Excel به‌صورت فایل XML Spreadsheet با پسوند `.xls` تولید می‌شود و با Microsoft Excel قابل بازشدن است.
- امتیازها برای خودبازبینی رفتار و پیگیری روند هستند؛ مقایسه افراد با نقش‌ها و زمینه‌های متفاوت نباید مبنای قضاوت ارزشی قرار گیرد.
- پس از استقرار، به دلیل تغییر cache، سرویس‌ورکر به v36 ارتقا یافته است.
