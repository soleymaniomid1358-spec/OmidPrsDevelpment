# مسیر رشد | نسخه اصلاح‌شده PWA

## تغییرات این نسخه
- ماتریس هفتگی روز × ساعت از ۷ تا ۲۲ بازگردانده شد.
- «ناهار و استراحت» از فعالیت‌های قابل تیک‌زدن حذف شد.
- برای هر فعالیت روزانه امکان ثبت Note و دسته‌بندی ثبت فعالیت اضافه شد.
- گزارش فعالیت‌ها قابلیت فیلتر بر اساس دسته، بازه تاریخ و جست‌وجو در عنوان/Note دارد.
- اطلاعات در localStorage همان مرورگر نگهداری می‌شود؛ پشتیبان JSON بگیرید.

## انتشار روی GitHub Pages
1. وارد https://github.com/new شوید و یک مخزن جدید (مثلاً `masire-roshd`) بسازید.
2. محتویات همین پوشه `pwa` را در ریشه مخزن بارگذاری کنید؛ `index.html` باید در ریشه باشد.
3. در مخزن به Settings → Pages بروید.
4. در Build and deployment گزینه Deploy from a branch را انتخاب کنید.
5. Branch را `main` و پوشه را `/(root)` انتخاب و Save کنید.
6. پس از انتشار، نشانی معمولاً `https://USERNAME.github.io/masire-roshd/` خواهد بود.
7. برای نصب iPhone، نشانی را در Safari باز کنید → Share → Add to Home Screen. در Android از منوی مرورگر گزینه Install app یا Add to Home screen را انتخاب کنید.

## نکات
- در این نسخه CACHE به v6 تغییر کرده تا فایل‌های قدیمی Service Worker پاک شوند.
- قبل از به‌روزرسانی، از بخش گزارش و پشتیبان خروجی JSON بگیرید.
- داده‌ها خودکار بین دستگاه‌ها همگام نمی‌شوند؛ برای انتقال دستگاه از Export/Import استفاده کنید.
