# مسیر رشد – نسخه ۲۲

این نسخه شامل اصلاح راه‌اندازی برنامه، ساختار دسته ← فعالیت ← زیر‌فعالیت، Drill Down/Up سلسله‌مراتبی، چک‌باکس‌های فشرده روزهای هفته، فیلتر تعاملی ماتریس روز × ساعت و حالت تمام‌صفحه است.

جزئیات تغییرات، آزمون‌های مرورگر و محدودیت‌های آزمون در `README_V22_FA.md` آمده است. راهنمای همگام‌سازی Supabase در `README_SYNC_FA.md` حفظ شده است.

## انتشار

ابتدا از اطلاعات برنامه پشتیبان JSON تهیه کنید. تمام فایل‌های داخل ZIP را در ریشه مخزن GitHub جایگزین کنید و Commit/Push انجام دهید. سپس صفحه را با `Ctrl+F5` بارگذاری کنید. شناسه JavaScript و Service Worker به نسخه ۲۲ افزایش یافته‌اند.
